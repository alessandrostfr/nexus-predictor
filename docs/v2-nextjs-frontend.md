# Nexus Predictor V2.10 - Next.js frontend layout refinement

This refinement keeps the V2.10 stack and visual identity but restores the MVP information architecture:

- Dashboard page with hero, year selector, edition summary, genre distribution, ranking preview and historical comparison.
- Ranking page with full filterable artist list.
- Rooms page with time-window selector, room map layout, saturation heatmap and import-contract cards.
- Artist profile page with MVP-like profile hero, metrics, history, scoring factors and related artists.

The frontend remains Next.js + TypeScript with custom CSS/design tokens. The V2.11 professional map block is still pending and is not implemented here.
